## Deviations
1. **"Toggle theme" is implemented by clicking the TopBar's theme control.** The theme preference is owned by `TopBar`'s local state; duplicating it in `App` would let the icon and the stored value drift apart. The palette command reuses the one control instead.
2. **One extra e2e check** (`palette_no_console_errors`) beyond the three specified.

## Questions / risks for the reviewer
1. **Enter runs `visible[activeIndex]`, with a fallback to `visible[0]`.** The index resets to 0 on query change, so the spec's "Enter runs the first row" holds for typing; after arrowing down, Enter runs the highlighted row, which is the expected listbox behaviour.
2. **Tool labels are `Switch to <navTitle>`, so `json-workbench` reads "Switch to JSON Workbench"** while the tool's H1 is a longer sentence. That is deliberate: the existing e2e suite and muscle memory depend on that phrasing.
3. **Recent entries duplicate the Tools entries** when a tool appears in both groups. They are distinct ids (`recent-…` vs `switch-…`), so keyboard order is stable, but the empty-query list shows the same destination twice. A design decision for CP1, not a defect.
