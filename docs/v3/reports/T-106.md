## Deviations
1. **Regex hand-off applies the pattern or the text, not the flags.** The spec asks to turn on every flag present in `/pattern/flags`. `UiFlags` lives outside the files I was authorised to read in this pass, so rather than guess at key names I applied `setPattern`/`setText` only. A follow-up one-liner once the flag keys are confirmed.
2. **`popover`→home link**: the privacy page is now reachable in-app, closing the T-105 gap.
3. **ToolHost renders `json-workbench` hidden on the home page** (spec-mandated keep-alive). It therefore downloads the JSON chunk, including CodeMirror, on first visit to `/`. See risk 1.

## Questions / risks for the reviewer
1. **Home-page first paint loads an editor the visitor did not ask for.** Keep-alive requires ToolHost to stay mounted, and the fallback id is `json-workbench`. Deferring the first mount until a tool route is opened would keep both properties and cut ~50 kB gzip plus the 173 kB CodeMirror chunk from the home page. Worth a decision at CP1.
2. **The secrets warning under-reports an embedded JWT.** Rule 1 matches a JWT only when it is the whole paste, so `curl … Bearer <jwt>` warns because the *redactor* finds the token, but does not suggest JWT Decoder. That is spec-correct and arguably right (the cURL is the better tool), but it reads oddly in the UI.
3. Focus-ring coverage for the new home controls uses the same `.focus-ring` utility as the shell; the check exercises the shell, not every home control individually.
