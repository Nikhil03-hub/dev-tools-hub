## Deviation and a bug the gate caught
- **No deviation from the spec's file list.**
- **Bug found and fixed during the task, worth recording.** My first `ToolHost` implementation computed the render list as `[...mounted, activeId].slice(-8)` while the effect de-duplicated. Switching back to an already-mounted tool therefore rendered it **twice** with the same key, producing two live CodeMirror editors and duplicate test ids. The suite caught it immediately with a hard failure, not a flake:
  `strict mode violation: locator('[data-testid="main-editor"] .cm-content') resolved to 2 elements`
  The render-time union now de-duplicates exactly like the effect does. The live probe above confirms `editorCount: 1` after a round trip. Recording it because a duplicate-mount is invisible in a screenshot and would have shown up later as "copy put the wrong text on the clipboard".
- **Validator provenance.** `check:registry` was tested in both directions rather than assumed: injecting one deliberately invalid entry produced exit **1** with **11** named problems (bad id, reserved slug, long title, long navTitle, short description, too few keywords, too few howTo, empty faq, self-reference, unknown related id, unknown icon); removing it produced exit **0**. `src/registry/meta.ts` was restored and `git diff` is empty.
