How to use

  1. In Chrome DevTools → Network, right-click the failing request → Copy → Copy as cURL.
  2. Paste it here together with the response.
  3. Read the findings, then open Share and copy the redacted report.

FAQ

Is my data uploaded?

No. This page's Content-Security-Policy blocks every connection; the browser itself refuses to send anything.

Will it catch every secret?

It redacts known token formats and secret-named fields. Unusual secrets can slip through, so review before sharing.
